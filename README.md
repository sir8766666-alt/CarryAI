# 🧠 What is CarryAI?

AI conversations contain valuable context.

Projects.  
Decisions.  
Instructions.  
Code.  
Research.  
Constraints.  
Ideas.  
Tasks.

But that context is usually trapped inside a single AI platform.

Switch from **Claude → Gemini**?

You often have to explain everything again.

Switch from **ChatGPT → Claude**?

Start copying messages.

CarryAI changes that.

> **CarryAI turns an AI conversation into a compact, portable `.ctx` file that can be carried between AI models.**

# ⚡ How It Works

```text
┌──────────────────────┐
│   AI Conversation    │
│                      │
│ Claude / ChatGPT /   │
│ Gemini / Other AI    │
└──────────┬───────────┘
           │
           │ Public Share Link
           ▼
┌──────────────────────┐
│       CarryAI        │
│                      │
│  Extract + Analyze   │
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│      Gemini AI       │
│                      │
│ Context Compression  │

└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│       .ctx File      │
│                      │
│ Goals                │

│ Constraints          │
│ Tasks                │
│ Code                 │
│ Important Context    │
└──────────┬───────────┘
           │
           │ Upload
           ▼
┌──────────────────────┐
│     Another AI       │
│                      │
│ Continue the work.   │
└──────────────────────┘
